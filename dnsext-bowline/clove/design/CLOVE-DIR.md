# clove: clove-dir の設計

clove が `clove-dir` に何を置き、どう使うかに関する設計書です。

## clove-dir

- `clove-dir`（既定値 `/var/clove/`）は、clove が状態を置くディレクトリです。
- clove は、設定ファイルを読んだあと、`clove-dir` を作業ディレクトリにします。
  - そのため、設定ファイルの中の相対パス（`tsig-file`、ログのファイル、ゾーンファイルの `source`、`spoof-*` のファイル）は、`clove-dir` から見たパスになります。
  - 設定ファイル自体のパス（コマンドラインで渡すもの）は、起動したディレクトリから見たパスです。
- `clove-dir` は、前もって作っておきます。無ければ起動できません。
- 2 つの clove で、同じ `clove-dir` を使ってはいけません。ゾーンのシリアルや鍵を、お互いに上書きしてしまいます。

## ゾーンごとのディレクトリ

- ゾーンごとに、`clove-dir` の下にディレクトリを 1 つ持ちます。最初に読み込むときに作ります。
- 名前は、ゾーン名から最後のドットを除いたものです（`example.jp.` なら `example.jp`）。
  - ルートゾーンだけは、そのままでは名前が空になるので、`root.` とします。
  - 最後にドットの付く名前は、ほかのゾーンからは生まれないので、`root.` が別のゾーンとぶつかることはありません。

## ゾーンのディレクトリに置くファイル

| ファイル | 置くゾーン | 中身 | モード |
|---|---|---|---|
| `serial` | すべて | 返しているシリアル | 0644 |
| `upstream-serial` | 上流から受け取って署名するゾーン | 上流のシリアル | 0644 |
| `<作った時刻>.ksk` | 署名するゾーン | KSK | 0600 |
| `<作った時刻>.zsk` | 署名するゾーン | ZSK | 0600 |

- シリアルについては [SERIAL.md](SERIAL.md)、鍵については [ZSK.md](ZSK.md) と [KSK.md](KSK.md) を参照してください。
- 鍵ファイルの名前は、作った時刻（ローカル時刻）を `YYYY-MM-DD-HH:MM:SS` の形にしたものです。
  - 同じ名前のファイルがあれば、1 秒ずつ進めて、空いている名前を使います。
- どのファイルも、`<名前>.tmp` に書いてから、本来の名前に付け替えます（`writeAtomic`）。
  - 書いている途中で止まっても、中途半端なファイルが本来の名前で残ることはありません。
  - `.tmp` で終わるファイルが残っていても、clove はそれを読みません。
- シリアルのファイルは、DB を作るのに成功したときにだけ書きます。

## ファイルを消したとき

| 消したファイル | 起きること |
|---|---|
| `serial`（ファイルから読み、署名しないゾーン） | 何も起きない。次の読み込みで書き直す |
| `serial`（上流から受け取り、署名しないゾーン） | 次の読み込みで、シリアルを比べずに、上流からゾーン全体を受け取る |
| `serial`（署名するゾーン） | 次に署名するとき、上流（またはゾーンファイル）のシリアルをそのまま返す。下流が持っているシリアルより小さくなることがある |
| `upstream-serial` | 次の読み込みで、上流からゾーン全体を一度受け取る |
| `.ksk` と `.zsk` | [ZSK.md](ZSK.md) と [KSK.md](KSK.md) を参照 |
| `.tmp` | 何も起きない |
